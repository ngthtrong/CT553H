1. 學習目標

DeepNeoAG 是整門課第一次真正進入 biological sequence prediction 的 project：word 換成 amino acid、DistilBERT 換成 Protein Language Model，而 downstream 的 1D CNN / MCNN 核心邏輯幾乎不變。

PLM representation理解 per-residue contextual embedding。
MCNN理解為什麼同一條 sequence 需要多種 window scales。
Imbalance知道稀少 positive class 下 Accuracy 為什麼會誤導。
Similarity control把同源/相似序列 leakage 視為 bioinformatics validity 的核心問題。
Independent evaluation模型選擇期間不碰 final test。
Scientific interpretation區分 predictive signal 與真正 mechanistic claim。

2. 生物學上的 prediction problem

Neoantigen 是與腫瘤突變相關的 peptide candidate；在適當 antigen processing、HLA presentation 與 T-cell context 下可能引發 anti-tumor immune response。DeepNeoAG 聚焦 sequence-based neoantigen epitope prediction，並以不要求 MHC allele 作為模型輸入為設計特色之一。

重要邊界：模型預測一條 peptide「neoantigen-like」並不等於證明它在真實病人中一定會被處理、被 HLA 呈現、被 T cell 認得或產生臨床療效。研究 endpoint 必須精確。

3. Published DeepNeoAG 做了什麼？

2024 DeepNeoAG 將 pretrained Protein Language Model representation 與 multi-window scanning CNN 結合。公開 repository 提供 ProtTrans、TAPE 與 ESM feature-generation workflow，也示範用 ESM-2 650M 產生 per-token features。

peptide sequence ↓ PLM per-residue representation ↓ Multi-window Conv1D local features ↓ feature integration ↓ neoantigen vs other

6. 為什麼一定要先做 One-hot baseline？

peptide ↓ 20-aa one-hot L × 20 ↓ Conv1D / MCNN ↓ classifier

這個 baseline 能隔離「只靠 supervised sequence order 可以學多少」；如果沒有它，就無法清楚說 PLM pretraining 到底貢獻多少。

7. ESM-2 per-residue embeddings

ESM 官方 repository 列出多個 ESM-2 checkpoints。例如 esm2_t33_650M_UR50D 有 33 層、約 650M parameters、embedding dimension 1280；官方 extraction 工具也區分 per_tok residue-level embedding 與 whole-sequence mean embedding。

S L Y N T V A T L ↓ ESM-2 9 residues × D dimensions ↓ L × D contextual residue matrix

教學時為了讓 Colab T4 能快速完成，可先用 esm2_t6_8M_UR50D 展示完整 pipeline；正式 reproduction 再回到 published feature protocol。

8. 在 PLM embedding 上做 Multi-window CNN

L × D PLM embeddings ├─ window 2 → filters → pool ┐ ├─ window 4 → filters → pool ┤ ├─ window 8 → filters → pool ┤ → concatenate → classifier └─ window 16 → filters → pool┘

不同 windows 是對「有用的 biological local scale」提出不同 hypothesis。不能直接把某個 window size 宣稱成 biological motif length；需要後續 interpretability 與 biological evidence。

9. Tensor shapes：真正和 IMDb 完全相同的地方

ESM output:           [B, L, D]
transpose for Conv1D: [B, D, L]
Conv1D output:        [B, F, L']
global max pooling:   [B, F]
multiple windows:     concatenate several [B, F] blocks

這和前一個 DistilBERT + MCNN project 幾乎完全一樣，這就是把兩題連在一起教的最大價值。

10. Class imbalance 現在變成核心研究問題

filtering 後 302 neoantigens 對 6,710 other peptides，約 1:22。

Accuracy trap：如果全部都猜 other，Accuracy 仍然非常高，但 neoantigen sensitivity = 0。

因此 weighted loss、sampling strategy、threshold selection 都應成為實驗，而 Precision/Recall/PR-AUC 必須正式報告。

11. Sequence similarity leakage

bioinformatics 最危險的問題之一，是 highly similar sequences 同時出現在 train 與 test。DeepNeoAG 公開資料表明確列出 <30% similarity filtering。

raw peptide candidates ↓ sequence similarity / redundancy control ↓ train-test separation ↓ model development ↓ independent evaluation
對照影像：就像不能把同一張照片的近重複版本分到 train/test；但蛋白質中 sequence homology 往往更容易讓模型記住 family-level signal，因此影響更嚴重。

14. 如何把 MCNN filter 往 biological interpretation 推進？

高 activation 的 local window 可以提示 predictive sequence pattern，但不能直接等同 biochemical motif 或 immune mechanism。

learned filter ↓ collect top-activating peptide windows ↓ sequence-logo / residue enrichment ↓ compare with known biology ↓ 形成保守 biological hypothesis ↓ 若要做 mechanistic claim → 實驗驗證

Processing/presentation預測不等於證明 natural processing 與 surface presentation。
T-cell responsepresentation 與 immunogenicity 是不同 biological stages。
External generalization應跨 cancer type、cohort 與 data source 驗證。
